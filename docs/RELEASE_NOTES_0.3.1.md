# v0.3.1

小修复版本，不需要数据迁移。

## 修复

- **#29 任务列表状态**：`waiting_for_capacity` 等后端状态现在显示中文（如「等待算力」），「进行中」计数也把排队、等算力、分配中的任务算进去。
- **#30 失败后实例一直「释放中」**：任务在创建运行时之前就失败时，实例直接收尾为「已释放」，不再停在「释放中」。同时 SQLite 改用 WAL 并把锁等待放宽到 30 秒，减少并发写入时的 `OperationalError`（database is locked）。
- **#31 工作流离线预览来回闪**：预览只在切换工作流时读取一次，不再随页面刷新反复重读；版本号是 `1.0.0` 这类字符串时也能正常打开，不再报「请求格式错误」。
- **首次启动建表冲突**：启动器同时拉起 API 和 worker，全新数据库上两边一起建表时可能报 `table already exists` 退出，现在建表跨进程串行。
- **#27 Windows 前端测试**：测试入口用 `fileURLToPath` 转换路径（感谢 @CyrusAuyeung，PR #28）。

## 验证

- 后端 513 项、前端 43 项测试通过；类型检查、生产构建和契约检查通过。
- 本版本没有跑真实 Colab/GPU 任务。

升级前请备份数据库和 `.env`。

## 下载与验证范围

桌面包内置 Python 与依赖；Android 为 Termux 后端包，不是 APK，首次启动需联网。Linux x86_64 做了原生启动和 Mock 任务检查；Windows、macOS 双架构和 Termux 只做了交叉构建与归档检查。归档不含 .env、数据库、OAuth 凭据或运行数据，校验见 SHA256SUMS.txt。
